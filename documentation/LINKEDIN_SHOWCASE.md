🚀 Excited to unveil **PARKIFY** – a complete, production-grade Smart Parking Management & Slot Reservation Platform built from the ground up!

Urban drivers spend up to 20 minutes circling blocks searching for parking, leading to congestion and carbon emissions. PARKIFY solves this through real-time parking bay allocation and transactional collision prevention.

### 🌟 Key Highlights & Engineering Features:
- ⚡ **Interactive Bay Matrix:** Live floor-by-floor occupancy visualization for 4-Wheelers, 2-Wheelers, and dedicated EV rapid charger bays.
- 🛡️ **Zero Double-Booking Guarantee:** Backed by database transactions to guarantee atomic allocations under high concurrent traffic.
- 💳 **Dynamic Tariff Engine:** Real-time billing computation based on scheduled durations and slot tiers.
- 🔐 **Enterprise Security:** JWT-based stateless authentication, salted Bcrypt password hashing, and Role-Based Access Control (RBAC).
- 📊 **Executive Operator Portal:** Comprehensive real-time metrics including occupancy rates, total revenue, inventory provisioning, and booking status controls.

### 🛠️ Tech Stack:
- **Frontend:** React 18, Vite, Context API, CSS Grid / Flexbox
- **Backend:** Node.js, Express.js REST API
- **Database & ORM:** PostgreSQL / Sequelize ORM (with seamless SQLite fallback)
- **Architecture:** 5 progressive academic modules mapping CO1 through CO6 (Vanilla JS -> React SPA -> Low-Level Node Streams & EventEmitter -> Express REST API -> Integrated Full Stack).
